# AR Murder Mystery (Unity 6)
## Popis

Mobilná AR hra vytvorená v Unity 6, kde hráč rieši vraždu pomocou interaktívneho casebooku (prípad, dôkazy, podozriví, obvinenie).

## Funkcionalita
Casebook UI
Inspect dôkazov (zobrazenie 3D modelu)
Otáčanie objektov
AR prvky (XR / AR Foundation)
Dynamické spawnovanie objektov

## Technológie
Unity 6
Visual Scripting
AR Foundation / XR Toolkit
